# CVAT Box Counter & Duplicate Inspector

Ứng dụng web dùng để đọc annotation CVAT, thống kê bounding box và phát hiện các box trùng lặp theo tọa độ hoặc IoU.

## Chạy trên máy local

Yêu cầu: Node.js.

```bash
npm install
npm run dev
```

Ứng dụng mặc định chạy tại `http://localhost:3000`.

## Kiểm tra mã nguồn

```bash
npm run lint
npm test
npm run build
```
