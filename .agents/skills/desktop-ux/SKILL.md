# CVAT Tool Desktop UX

## Objective
Transform CVAT Tool into a professional, modern,
efficient desktop application.

## Skill orchestration
- desktop-ux: Architecture and feature preservation
- ui-ux-pro-max: Design system and UX planning
- frontend-design: UI implementation
- impeccable: Visual audit and refinement

## Critical requirements
- Preserve 100% of existing functionality.
- Do not rewrite business logic unnecessarily.
- Preserve CVAT API integrations.
- Preserve PAT authentication functionality.
- Do not expose or log authentication tokens.
- Preserve server connection settings.
- Preserve existing configuration compatibility.
- Do not change the application framework
  without explicit approval.

## UX requirements
- Professional desktop application layout.
- Clear navigation and feature grouping.
- Consistent design system.
- Efficient data tables and filters.
- Responsive resizing.
- Proper loading and error states.
- Keyboard navigation.
- Clear server connection feedback.

## Workflow
1. Audit the complete source code.
2. Inventory all existing features.
3. Analyze the current UI architecture.
4. Propose a new information architecture.
5. Create a professional design system.
6. Wait for approval.
7. Implement changes incrementally.
8. Validate existing workflows and API calls.
9. Test the packaged desktop application.
